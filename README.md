# MindShift E-commerce Website

## 📌 Project Description
This is a responsive e-commerce website built using HTML, CSS, and JavaScript.  
The project showcases a clean UI, product display sections, and basic website navigation.

## 🌐 Live Demo
🔗 https://gomathim387-bit.github.io/MindShift-E-commerce-Website/

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run Locally
1. Download or clone the repository  
2. Open `index.html` in your browser  

## 🚀 How to Use / Open Template
1. **Unzip the folder** (`Book E-commerce Website.zip`)  
2. Open the folder → double-click **index.html** in your browser to see the website  
3. Folder structure:
4. **Edit Content / Replace Images:**  
   - All **book images** are in `img/`  
   - Logo is in `logo/Logo.png`  
   - To replace a book cover, **replace the image** in `img/` and ensure the file name matches the JS reference  
   - CSS files are in `css/` → edit colors, fonts, layout  
   - JS files are in `js/` → edit search, book filtering, or interactivity  

5. **Open Other Pages:**  
   - `book.html` → Book details / buy page  
   - `contact.html` → Contact page
